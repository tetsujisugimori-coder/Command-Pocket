# Command Pocket
スキル呼び出し文、ショートカット、シェルコマンドを集めて、検索・コピーするブラウザアプリです。

## 使い方
GitHub Pagesで公開した画面を開きます。ログイン不要です。
- 種類・環境・キーワードで絞り込んでコピーできます。
- 名前・説明・本文・タグを登録、編集、削除できます。
- `{{PR_URL}}` のような英数字・アンダースコアの差し替え欄を本文に書くと、コピー前に値を入力できます。
- スキル4件、Git・PowerShellコマンド5件、Windows・VS Codeショートカット3件を初期サンプルとして収録しています。
- ショートカットはキーの組み合わせを表す文字列としてコピーします。登録コマンドやスキルをこのアプリから実行する機能はありません。

## 保存と移行
登録内容は、このサイトを開いているブラウザのlocalStorageに保存します。サーバーへの送信・端末間の自動同期はありません。別の端末・ブラウザへの移行には「バックアップを書き出す」「バックアップを読み込む」を使ってください。読み込みは全件置換で、確認画面があります。
Sites版からGitHub Pages版への移動でも保存領域は変わります。Sites版で書き出してから、新しい公開版で読み込んでください。ブラウザデータを消すと登録内容も失われるため、必要に応じてバックアップしてください。プライベートブラウズでは永続保存を前提にしないでください。
公開リポジトリに含むのはプログラムと初期サンプルのみです。利用者がブラウザで登録したデータやバックアップは含みません。

## 開発・公開
依存パッケージやビルドは不要です。
```sh
python -m http.server 8000 --directory docs
node --check docs/app.js
```
ローカルでの表示先は `http://localhost:8000` です。クリップボード機能はHTTPSまたはlocalhostで利用します。許可されない環境では本文を表示して手動コピーします。
GitHub Pagesの公開元は `main` ブランチの `/docs` フォルダです。`.nojekyll` により静的ファイルとして配信します。
Google Fontsを利用し、利用できない場合は端末のフォントに切り替わります。

## 構成
- `docs/index.html` : 画面
- `docs/style.css` : レイアウト・レスポンシブ表示
- `docs/app.js` : 登録・検索・コピー・保存・バックアップ
- `LOG.md` : 変更と検証の記録
